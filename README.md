# Shelter Finder

Shelter Finder is a single-page HTML app for registering animal shelters and browsing shelter locations by animal type. It includes contact information, photo previews, saved shelters, translated UI text, and an interactive map with built-in shelter examples.

## Open the app

Open `outputs/index.html` in a browser.

## Current status

This is a frontend-only prototype. User-added shelters are saved in browser local storage, not in a backend database.
